# SLC-AS-EPM_I_DOCSIS_ProvisionSpectrumElements

## About

This interactive automation script can be used to provision spectrum elements for existing CCAP elements using the connector *Cisco CBR-8 UTSC* (Production version).

## Key Features

- Ability to define custom Get/Set SNMP community strings during element provisioning.
- Option to specify the view in which the spectrum element will be placed.
- Flexibility to determine the DataMiner Agent where the spectrum element should be provisioned.
